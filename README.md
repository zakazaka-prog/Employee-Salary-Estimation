# Employee Salary Estimation Using Machine Learning

A beginner-friendly BTech CSE / Machine Learning project that estimates an employee's **annual salary in Indian rupees (INR)** using:

- Job role
- Years of experience
- Working hours per week

The project uses **Random Forest Regression** and provides both a command-line predictor and a Streamlit web interface.

> **Important:** The included CSV is synthetic demonstration data generated by `generate_dataset.py`. It is not collected from real employees and must not be treated as a reliable salary survey or used for real hiring/pay decisions. Replace it with a properly licensed, representative real dataset before making real-world claims.

## Setup

Open a terminal in the project folder.

### 1. Create and activate a virtual environment (recommended)

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install libraries

```bash
python -m pip install -r requirements.txt
```

### 3. Generate the dataset

The generated CSV is already included. To regenerate it:

```bash
python generate_dataset.py
```

### 4. Train the model

```bash
python train_model.py
```

This trains a Random Forest Regression pipeline, evaluates it on a held-out test set, and saves the model and evaluation metrics in `model/`.

### 5. Run the web application

```bash
streamlit run app.py
```

Streamlit will show a local URL in the terminal. Open that URL in your browser.

### Alternative: command-line prediction

```bash
python predict_salary.py
```

Enter a job role, experience, and weekly working hours when prompted.

## Machine Learning workflow

1. **Data collection:** Load the employee salary CSV.
2. **Preprocessing:** Encode the categorical `Job_Role` column using One-Hot Encoding.
3. **Feature selection:** Use job role, experience, and weekly working hours as input features.
4. **Train/test split:** Keep 80% of records for training and 20% for testing.
5. **Model training:** Fit a Random Forest Regressor.
6. **Evaluation:** Report MAE, RMSE, and R² on the test set.
7. **Prediction:** Use the saved pipeline to estimate annual salary for new inputs.

## Input and output

| Input | Example |
|---|---|
| Job role | Software Engineer |
| Experience | 3 years |
| Working hours | 40 hours/week |

**Output:** Estimated annual salary in INR.

The actual output is produced by the trained model. It may differ when the dataset or model settings change.

## Algorithm: Random Forest Regression

Random Forest Regression combines predictions from multiple decision trees. It can model non-linear relationships between employee attributes and salary.

## Evaluation metrics

- **MAE (Mean Absolute Error):** Average absolute difference between actual and predicted salaries. Lower is better.
- **RMSE (Root Mean Squared Error):** Penalizes larger prediction errors more strongly. Lower is better.
- **R² score:** Measures how much variation in the test target is explained by the model. Values closer to 1 generally indicate a better fit.

Metrics from this synthetic dataset measure how well the model learns the synthetic data-generation pattern; they do not establish real-world salary accuracy.
